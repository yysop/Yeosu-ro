# 여수 지도

Figma Make에서 만든 화면을 독립 실행형 React 웹 프로젝트로 정리했습니다.

## 실행

Node.js 20.19 이상과 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

화면에 표시된 로컬 주소로 접속하세요. 배포용 파일은 `pnpm build`로 `dist/`에 생성됩니다.

## 코드 구성

| 경로 | 역할 |
| --- | --- |
| `src/App.tsx` | 지도, 필터, 상세 패널, 장소 추가·삭제 UI |
| `src/data/places.ts` | 기본 관광명소·맛집 데이터 |
| `src/index.css` | 글꼴, 색상, 지도 스타일 |
| `src/main.tsx` | React 시작점 |

추가한 장소는 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기와 동기화하려면 별도 서버와 데이터베이스가 필요합니다. 지도 타일과 글꼴은 인터넷 연결을 사용합니다. 기본 장소의 영업시간·주소·링크는 운영 전 최신 정보로 확인하세요.
